# glitched.sh — UI

> *You didn't fail. The system did. Three questions. A real plan.*

Frontend for [glitched.sh](https://glitched.sh) — a career pivot tool for displaced white-collar professionals. Users answer 3 questions and receive a personalized 30/60/90 day action plan generated by a 5-agent Claude pipeline.

---

## Stack

| Layer | Choice |
|-------|--------|
| Framework | Next.js 16 (App Router) |
| Language | TypeScript — strict mode, no `any` |
| Styling | Inline styles only — dual-theme token system |
| AI | Anthropic SDK (`claude-sonnet-4-20250514`) |
| Payments | Stripe (tip jar) |
| Email | Resend (plan refresh subscription) |
| Bot protection | Cloudflare Turnstile |
| Deploy | Vercel |

## Getting Started

### Prerequisites

```bash
node --version   # 18.17+
npm --version    # 9+
```

### Install

```bash
npm install
```

### Environment

Copy the example env file and fill in your values:

```bash
cp .env.local.example .env.local
```

```bash
# .env.local

ANTHROPIC_API_KEY=sk-ant-...
STRIPE_SECRET_KEY=sk_test_...
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_test_...
RESEND_API_KEY=re_...
RESEND_FROM_EMAIL=hello@glitched.sh
RESEND_AUDIENCE_ID=...
NEXT_PUBLIC_APP_URL=http://localhost:3000

# Cloudflare Turnstile — bot protection on /api/analyze
# dash.cloudflare.com → Security → Turnstile → create site
# Add localhost + production domain to the site's allowed domains
NEXT_PUBLIC_TURNSTILE_SITE_KEY=0x4AAAAAAA...   # safe for client
TURNSTILE_SECRET_KEY=0x4AAAAAAA...              # server only — never NEXT_PUBLIC_
```

See [API Configuration](#api-configuration) below for the agent pipeline options.

### Run

```bash
npm run dev      # http://localhost:3000
```

## API Configuration

The agent pipeline (5-agent Claude analysis) lives in a **private repo** and is not included here. Three modes are supported — set one in `.env.local`:

### Option 1 — External API service (recommended for production)

```bash
# Point to your deployed private API
AGENTS_API_URL=https://api.glitched.sh
# Optional: shared secret for auth
AGENTS_API_SECRET=your-secret
```

The `/api/analyze` route forwards POST requests to `${AGENTS_API_URL}/analyze`.

### Option 2 — Local npm package (monorepo setup)

Install the private package as a local dependency:

```bash
npm install ../glitched-agents   # path to your local clone
```

The route auto-detects and imports `@glitched/agents` at runtime.

### Option 3 — Mock mode (dev / testing)

```bash
NEXT_PUBLIC_USE_MOCK=true
```

The client returns `MOCK_RESULT` after a simulated delay — no API call is made. The breathing screen still plays in full.

You can also jump directly to the plan screen with real mock data via URL:

```
http://localhost:3000/?mock=plan
```

## User Flow

```
LandingScreen → IntakeScreen (3 questions) → BreathingScreen (~20s) → PlanScreen
```

- **Landing** — hero, CTA
- **Intake** — 3 sequential questions (role, want, fear) with progress bar
- **Breathing** — animated orb + affirmations while the API processes (~8–15s). The animation and the API finish simultaneously — no separate loading spinner.
- **Plan** — profile summary, 3 paths with fit scores, 30/60/90 plan, tip jar, email capture

## Theme System

The entire UI uses a dual-theme token system. **Never hardcode colors.**

```typescript
// ALWAYS use theme tokens via useTheme()
const { t, isDark } = useTheme();

style={{ color: t.text, background: t.bgCard }}

// WRONG
style={{ color: "#FDFAF4", background: "rgba(245,237,214,0.04)" }}
```

Token definitions live in `src/components/Glitched.tsx` (`DARK` and `LIGHT` objects). When adding new UI elements, add tokens to **both** objects.

## Testing

### Unit tests (Vitest)

```bash
npm run test
```

Tests cover:
- AWAF schema validation (the integrity check all agent output passes through)
- Mock result completeness
- Theme token key count (catches accidental deletions)

### E2E tests (Playwright)

```bash
# Start dev server first
npm run dev

# In another terminal
npm run test:e2e
```

Critical flows covered:
- Full intake → breathing → plan flow (API mocked via Playwright route interception)
- Theme toggle
- `?mock=plan` direct navigation
- Tip jar rendering
- Email capture submit + success state

### What NOT to do in tests

```typescript
// Never call real Anthropic/Stripe/Resend in tests
// tests/unit/setup.ts mocks all external services automatically
```

## Deploy

```bash
npm run build        # Verify clean build
npm run test         # All unit tests green
```

Then deploy to Vercel:

```bash
npm install -g vercel
vercel
```

Add all env vars from `.env.local` in `Vercel Dashboard → Settings → Environment Variables`. For Turnstile, also add your production domain to the site's allowed domains list in the Cloudflare dashboard.

Custom domain: `Settings → Domains → glitched.sh`
